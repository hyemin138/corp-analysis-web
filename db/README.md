# db

Supabase 데이터베이스 구조 및 보안 설정

## 파일 구성
- `erd.png` : ERD (테이블 관계도)

## 테이블 설명
| 테이블 | 설명 | 주요 컬럼 |
|---|---|---|
| (테이블 확정 후 작성) | | |

## 보안 (RLS)
- 테이블별 RLS(행 수준 보안) 활성화
- 관리자/일반 사용자 권한 구분 (정책 확정 후 작성)

## 데이터 적재
- `data/processed/`의 최종 데이터를 Supabase에 적재

## 참고
- Supabase 접속 키는 `.env`로 관리하며 레포에 포함하지 않음
- service_role 키는 프론트엔드 코드에 사용하지 않음
