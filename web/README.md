# web

태웅로직스 기업분석 웹서비스 (React + Supabase, Vercel 배포)

## 주요 기능
- 랜딩 페이지
- 로그인 (비즈니스 사용자 / 관리자 구분)
- 핵심 요약 대시보드
- TRACK1 : 국제환경·해상운임 대시보드
- TRACK2 : 태웅로직스 수익성 대시보드
- 마이페이지·설정
- 관리자 페이지 (관리자 추가·삭제)

## 배포
- Vercel (Root Directory: `web`)
- 배포 주소 : (배포 후 작성)

## 환경변수
- `.env.example` 참고, 실제 키는 `.env`에 작성 (레포에 포함하지 않음)
- Vercel 배포 시 Environment Variables에 등록
