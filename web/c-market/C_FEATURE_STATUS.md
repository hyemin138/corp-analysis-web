# 기능 현황

|화면|현재 구현|
|---|---|
|시장 현황|KCCI/SCFI/CCFI,시점별 KPI,기간필터,절대/상대차트,내보내기|
|항로 비교|13항로·종합·EUMED,복수선택,순위·전항로표,기준첫관측비교|
|시장 상태|9설명상태,192개 완전발표일,62구간·53전환,분포·지속·과거일탐색|
|통항|4경로,일별/주간,관측창,0척 분모·결측안내,운임병렬|
|예측 검증|11사양·80원점,연도/원점/모형필터,실측·예측·오차·구간·방향|
|종합 탐색|공통날짜와 운임·14항목항로표·상태·통항·완전성 연동|

공통: 확대·툴팁·범례·CSV·PNG 도구,필터초기화·저장·범위밖안내. PNG 파일저장 전수검사는 하지 않았다. 지도·새 예측생성·실시간수집·실제 DB/API·모바일은 제공하지 않는다. API provider 경계는 있으나 팀 전체 셸 연결은 미완료(셸 자체 미존재)다.

실자료 화면은 내부 스냅샷 가져오기 후 동작한다. 공개 저장소만 클론하면 명시적 자료없음 안내를 표시한다. 전체 연구는 CONDITIONAL_REVIEW이며 앱 검증 PASS와 구분한다.
