# 연구 해석과 데이터 제한

9개 상태는 고정 임계값의 설명용 수준×방향이며 자연 군집이나 인과적 구조변화가 아니다. 변동성은 별도 축이다. 192개 완전입력 발표일,62개 구간·53회 라벨 전환을 사용하며 미배정·공백을 숨기지 않는다. 고정 개발기준의 후향 상태 설명은 당시 실시간 가용정보 검증과 다르다.

PortWatch는 관측 빈티지·최초 공개시각이 미검증이다. 통항과 운임의 동행을 인과로 보지 않으며 수에즈 감소가 모두 희망봉으로 이동했다고 단정하지 않는다. 주간 값은 KCCI 발표일의 직전7일 관측창이다. 결측을0으로 채우지 않으며 실제0은 보존한다.

EUMED는 (2×유럽KNEI+지중해KMDI)/3 시장 대리지표다. 태웅의 회사 운송량·계약운임·이익 예측이 아니다. 11사양의80원점 후향 평가(2025년44·2026년36)는 이미 관찰된 탐색 표본이며 미래 독립 성능을 증명하지 않는다. 겹치는28일 창은 독립 관측이 아니다. 구간은 사후 보정 한계가 있고 확정 범위가 아니다.

actual_available=true만 정확도에 포함한다. EUMED_H28 탐색 평가에서 미실현110행을 제외하며, 전체 저장파일의 미실현184행은 다른 목표·개발기간도 포함한 별도 수치다. 0변화 점예측 FLAT과 이진평가 DOWN 규칙은 별개다. 과거68/62개 원 예측행은 미복구이며 재생성하지 않았다. 새 예측 버튼은 제공하지 않는다.

최신 관측일은 지표별 다르다. 마지막 KCCI11/09,중국지수11/13,통항11/01,완전상태11/02를 구분한다. 스냅샷을 실시간 시장현황으로 표시하지 않는다. 중국 원자료의2019~2022행도 보존하지만 공통 UI 시작은2022-11-07이다.

원연구·수익성 결론은 CONDITIONAL_REVIEW다. 기존 독립 앱 V1의 Vera PASS_WITH_LIMITATIONS·Editor 디자인/설명 PASS는 그 판본의 검사이며 49e13b5 팀 이식에서는 동일 입력·산식의 범위에 한해 재사용했다. V2의 최종 검수 상태는 C_V2_FINAL_QA_STATUS.md를 따른다. 어느 앱 검사도 공공데이터 재배포 허가·원연구 전체 인과검증·미래 운영 승인이 아니다. 공개 GitHub에 내부 원자료는 올리지 않는다.
