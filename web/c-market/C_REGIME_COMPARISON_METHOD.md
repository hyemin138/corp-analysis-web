# 같은 상태의 과거 사례 비교

대상은 primary_eligible=true인192개 발표일이다. 기존대표상태 level×direction9개와 변동성 별도축을 보존한다. 상태선택 후 해당상태의 실제날짜만 A/B 선택에 제공한다. 유사도 점수·추천모형·새 임계값은 만들지 않는다.

공통점: 두 날짜의 대표상태가 정확히 같고 입력완전인지를 확인한다. 차이점: 원 KCCI·8회변동성·4경로 mean7 및 B−A. null이 있으면 차이도null이다. A/B 각각의 실제통항창을 표시한다. 같은 날짜를 고른 경우 차이가 없다는 안내를 제공한다.

항로별 변화는 각 날짜 이하의 최신발표와4번째 이전 실제발표 간 단순변화율이다. 달력28일과 같다고 가정하지 않으며 두 날짜의 기준발표일을 표에 명시한다. EUMED는 시장합성지수이고 실제회사계약가중치가 아니다.

공통 시장기간 필터는 비교화면에 노출하지 않는다. A/B는 독립적인 사례선택이며 전역기간의 무효필터가 아니다. A/B 탐색 버튼을 누를 때만 전역관측일·필요한 표시기간을 명시적으로 이동한다.

원62구간·53전환·상태별횟수/날짜는 펼침근거와CSV에 보존했다. 달력범위=end−start,관측수와 interval_coverage는 별개다. 구간은 자료끝·공백에서 중도절단될 수 있고 구조변화점이 아니다. 같은 상태는 미래운임·기업수익성의 동일성을 뜻하지 않는다.
