# 선택한 구조: 네 가지 목적 중심 영역

단일 긴 페이지는 예측과 시장 관측의 날짜 의미가 섞이고,세영역+하위탭은 상태비교가 묻힐 수 있다. 기존6메뉴는 현황/종합탐색 및 운임/통항의 반복이 컸다. 네영역을 선택한다.

1. **시장 변화** — 스냅샷의 현재선택일을 읽고,기간의 항로 격차를 확인한다. 규칙 관찰→근거→공통기준100·순위→점검질문 순서다.
2. **운임·통항 탐색** — 공통기간에 운임과4경로 통항을 별도축으로 놓고 동기 커서/선택일과 상태 타임라인을 연결한다. 최초공개시각과 관측창의 차이를 유지한다.
3. **같은 상태 비교** — 같은 대표상태의 완전관측 목록에서 A/B를 고른다. 공통점→수준/변동성/항로/통항 차이→한계를 비교한다. 최근접 예측모형이나 유사사례 추천 점수를 새로 만들지 않는다.
4. **예측 신뢰도** — 시장관측일과 다른 원점 필터. 모형과연도→실제/예측→큰오차 선택→구간 폭/포함→원점이하 시장정보→11모형/통계 상세로 이어진다.

전역: 시장 기간·관측선택일·운임/항로·통항경로. 비교상태·A/B와 예측모형/원점/연도는 의미가 달라 별도로 보존한다. 예측에서 원점환경 버튼을 누를 때만 명시적으로 시장날짜와 기간을 변경한다.

기본 관찰과 방법론을 분리하고 긴 원자료·구간·11모형표는 details로 제공한다. 시장/통항은 공통 interpretMarket와 InterpretationPanel을 사용한다. 비교/예측은 실제 차이·오차 계산에 연결한 별도 질문 템플릿을 공통 CheckQuestions 컴포넌트로 표시한다. 모든 질문이 하나의 함수에서 생성된다는 뜻은 아니다. 기간 변화는 기간 끝값,선택일 상태는 선택일 이하 최신 발표값임을 각각 표시한다. 보관된2026-11 스냅샷이며 오늘의 실시간 시장이 아니다.
