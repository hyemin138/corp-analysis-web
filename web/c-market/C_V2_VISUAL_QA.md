# V2 시각 검수 — Kit

qa/v2/screenshots/{1920,1600,1366}_{market,context,compare,forecast}.png의12장이 현재 후보의 전체 화면이다. V1의18장은 qa/v2_baseline/screenshots에 보존했다. qa/v2/BEFORE_AFTER_TOP.png는 같은1366폭의 최초 뷰 비교,CONTACT_1366.png는4영역 전체 구성의 연락판이다.

Kit은 전후 최초 뷰와4영역 연락판,1366폭의 운임통항·상태비교·예측 상단을 실제로 열람했다. 차트와 표가 잘리거나 서로 겹치는 현상은 이 열람에서 발견되지 않았다. 상태 타임라인의 왼쪽 여백을 늘려 한글 범주가 들어갈 공간을 확보했다. 글자를 줄여 내용을 끼워 넣지 않았다.

V1 대비 메뉴6→4,기본 시장 KPI4→3,독립시점탐색 제거,상태 분포/지속 막대와모형 비교 막대 제거가 실제 화면에 반영됐다. 근거는 삭제하지 않고 원구간·날짜·CSV와11모형/민감도 펼침으로 옮겼다. 대신 공통근거·기간의 격차·A/B 차이·예측 실패와구간폭을 중심에 배치했다.

교환관계: 시장 변화의 기본 화면에서 관찰 설명이 늘어 첫 그래프가 V1보다 아래에 위치한다. 숫자와 해석을 먼저 읽도록 한 선택이며 단순히 화면 수가 줄었다고 시각적 개선을 확정하지 않는다. Editor의 독립 사용성 검토와 최종 결함 수정을 반영한다.

세 해상도의 자동 넘침 검사는 모든 글리프·툴팁 상태·접근성을 증명하지 않는다. Root가12장 전체를 개별 확대 열람했다고 주장하지 않는다. Editor의 실제 열람·조작 범위는 독립 보고서를 따른다.

추가 재검수에서 Editor가22파일판의 시간축 하루 밀림과 주간 커서의 관측 없는 날 빈발을 발견했다. UTC좌표/눈금 기준과 실제 관측일 스냅을 수정했다. 현재23파일판의12장은 최신26개브라우저 실행에서 갱신됐고,UTC/Seoul의7개시간차트14개PNG를 별도비교했다. 픽셀일치·주간41곳사용성검사를 통과했으며 최신 독립 확인은 Editor TIME_FINAL_RECHECK 및 Vera FINAL_RECHECK에서 필수0으로 종결됐다. 변화율 모드의 약6px 그림영역 차이 등 비차단 사항은 독립 요약에 명시했다. 초기 연락판/상단 열람은 당시레이아웃 검수 범위로만 읽어야 한다.
