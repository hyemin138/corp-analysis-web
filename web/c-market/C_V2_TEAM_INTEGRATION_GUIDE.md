# 팀 프로젝트 통합 안내

현재 팀 저장소는 `analysis/`, `db/`, `preprocessing/`, `web/`의 안내 파일 중심입니다. 공통 React 라우터·인증·실행 API·DB 스키마가 구현된 것으로 가정하지 않았습니다. C 모듈은 `web/c-market`에서 독립 실행합니다.

## 전달물 구분

- PR #2: C 소스, 의존성 잠금, 테스트, 방법 및 통합 문서, 자체 연구의 최소 집계 통계.
- 내부 ZIP: 같은 소스와 검증 데이터 한 사본, 동결 빌드, 화면 증거, 독립 QA 및 검증 로그.
- 기존 독립 앱·원 연구·53종 데이터 통합본: 읽기 전용으로 유지. 전체를 팀 Git에 복제하지 않음.

## DB/API 연결 시 작업

1. `src/data/provider.ts`의 `MarketDataProvider.load(signal)` 공급원을 팀 API 변환기로 교체합니다.
2. 기존 `MarketData`의 날짜 의미, 숫자/null/boolean, 계열별 시간순, 실제값 가용성, 통항 관측창을 유지합니다.
3. 현재 고정 스냅샷의 201행 검증은 API 갱신 정책에 맞게 재검토합니다. 단순히 새 응답을 기존 JSON이라고 가정하지 않습니다.
4. 팀 호스트의 라우터·인증·CSS 범위를 연결하고, C의 독립 필터 상태와 호환성을 검사합니다.
5. 실제 API에 대해 현재 데이터·브라우저 회귀를 다시 실행합니다.

이 문서는 DB 테이블, PK/FK, 정규화, 공식 엔드포인트를 확정하지 않습니다. 필요한 입력은 `C_V2_DATA_API_REQUIREMENTS.md`를 따릅니다. 원 데이터나 연구 결론을 바꾸지 않고 공급 계층을 교체하는 것이 목표입니다.

V1 기준은 Git `49e13b5`, 신규 작업은 같은 `feat/c-market-dashboard`입니다. main 병합·운영 배포는 수행하지 않습니다. 코드의 삭제·통합 근거는 `C_V2_FEATURE_AUDIT.md`에 있습니다.
