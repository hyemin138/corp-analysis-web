# 운임·통항 통합 탐색

운임은 원 KCCI/EUMED 발표일,통항은 원 일별 관측 또는 기존features의 발표일 키7일평균이다. 주간 통항은 observation_start~observation_end를 원값 그대로 보존하며 보통 발표일−7~−1일이다. 마지막 통항2026-11-01,11/02특징창10/26~11/01,11/09주간통항 미확보를 유지한다.

같은 기간을 두 차트의 시간범위로 사용하고 타임스탬프 연결그룹으로 커서·확대영역을 연결한다. 주간/일별 배열의 길이가 달라 dataIndex로 연결하지 않는다. 커서는 두 차트 실제 날짜의 합집합에서 가까운 날짜로 맞춘다. 주간은 실제 발표일(휴일 조정 포함),일별은 실제 관측일에 맞는다. 해당일의 레코드가 없는 상대계열은 '해당일 관측 없음', 레코드 값이 null이면 '미확보'다. 날짜를 먼저 명시적으로 맞춘 뒤 그날의 원값만 읽으며 보간·다른 날짜의 값 대체는 하지 않는다. 주간 관측창과 값 단위는 별도로 표시한다.

시간축은 관측 날짜를 UTC 자정의 수치 좌표로 변환하고 ECharts useUTC 및 눈금·툴팁·선택선을 같은 기준으로 통일한다. UTC 자정은 그래프 좌표의 정의이며 실제 발표시각이 아니다. 기존 날짜 문자열·가용일 가정·집계창·예측목표는 변경하지 않았다. UTC/Asia-Seoul에서 월 경계 차트 픽셀과 날짜를 비교하고 Node의 UTC/Seoul/New York 달력 검사를 별도로 수행한다.

원단위와 기간변화율을 전환한다. 상대값은 운임·경로마다 기간첫유효 숫자 기준이며 기준일을 설명한다. 실제0을 건너뛰지 않으며 기준0이면 그계열 변화율null·원단위 확인안내를 보인다. 계열/경로 미선택·전부결측은 명시적 빈화면이다.

차트·상태타임라인의 클릭은 실제관측 날짜를 선택해 상태/통항표를 갱신한다. 원점환경에서 이동한 화면은 회고탐색이다. 최초공개시각이 미검증인 PortWatch를 당시 실시간 입력으로 주장하지 않는다. 이후 관측은 당시 예측정보가 아니다. 자료를 새로수집하거나 미래날짜로 채우지 않는다.

통항량은 컨테이너선 척수이며TEU·회사운송량이 아니다. 수에즈감소의 희망봉이동·운임인과효과를 확정하지 않는다.
