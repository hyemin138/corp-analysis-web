# 공개 저장소와 내부 인계 자료의 범위

공개 Git에는 C 앱 소스·테스트·방법 문서와 연구자가 계산한 최소한의 집계 통계 참조를 포함한다. src/data/researchEvidence.json은 기존 자체 연구의 모델별 집계오차·표본수·검정값·출처 CSV의 SHA다. 지수 관측 원행·원점별 실제값·계약/고객 자료가 아니다. 대시보드에 제시하는 기존 통계검정의 근거를 코드에서 확인하기 위한 참조다.

공공 지수·PortWatch의 재배포 권한을 이 문서로 승인하지 않는다. 내부 스냅샷 public/data/market.json, 원 CSV, 로컬 가용성 기록, QA 스크린샷, dist는 공개 Git에서 제외한다. 이 자료들은 팀 내부 ZIP에만 포함한다. 인증키·계정 설정·토큰·가상환경·node_modules·원마스터는 두 패키지 모두에서 제외한다.

공개 클론은 내부 자료 없이 코드 테스트·빌드를 할 수 있지만 실자료 화면은 팀 내부 스냅샷이 필요하다. 통계 참조의 집계 결과를 새로운 미래 예측 정확도나 운영 승인으로 해석하지 않는다.
