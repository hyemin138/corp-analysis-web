# 데이터 품질·보류 이슈 요약

이 문서는 업로드된 `Track2_B_검토및인계.xlsx`의 **분기선별**, **보류항목** 시트와 이번에 첨부된 파이썬 코드와 최종 인계 ZIP의 `qa/` 원본을 바탕으로 작성했습니다. 해당 시점 이후 신규 공시를 재수집하거나 원본 ZIP을 다시 검증한 결과는 아닙니다.

## 이번 패키지에서 직접 확인한 값

| 검토 항목 | 값 | 검증 방법 |
| --- | ---: | --- |
| 분기 수 | 26 | 엑셀 분기선별 2020Q1~2026Q2 행 수 재집계 |
| 분석 지표 수 | 23 | 분기선별 시트의 금액·비율 열 수 (메타데이터 3열 제외) |
| 전체 분기×지표 칸 | 598 | 26 × 23 재계산 |
| 값이 있는 칸 | 543 | 분기선별 시트 빈칸 제외 재집계 |
| 매출채권 합계 대조 | 26개 분기 | 총액 − 충당금 − 순액; 절댓값 최대 **0.00001억원(1천원)** |
| 보류·주의 목록 | 13건 | 최종 인계 ZIP의 `qa/review_register.csv` 그대로 반영 |

위의 **합계 대조는 공개용 엑셀에서 재계산한 것**이고, 원문과 독립적으로 대조했다는 뜻은 아닙니다. 원단위·표시단위 차이를 임의로 수정하지 않았습니다.

## 독립 재현 제한

- 이번 업로드에는 원본 공시 ZIP/HTML 및 상태 DB와 19,644개 후보 표 전체는 **포함되지 않습니다**. 대신 최종 결과 CSV·29건 원문 목록·셀별 판단·Q4 검토 증거가 `examples/`, `docs/evidence/`에 있습니다.
- 따라서 **원본 파일의 SHA-256 검증 및 보류 항목의 근거 표 대조를 이번 환경에서 재실시하지 않았습니다(확인필요).**
- 인계 Excel은 후속 검토 과정을 반영한 스냅샷으로, 코드 4개만으로 동일한 Excel 생성이 보장되지 않습니다.
- 이 자료는 **원인 진단용 데이터**이지 대손 위험이나 영업이익을 예측하도록 검증된 모델 입력셋이 아닙니다.
