# analysis

전처리된 데이터로 탐색적 분석(EDA), 가설 검증, 예측 모델링을 수행하는 코드

## 폴더 구성
- `track1/` : 국제환경·해상운임 분석 (KCCI 운임 예측 모델링)
- `track2/` : 태웅로직스 수익성 분석 (수익성 악화 원인 가설 검증)

## preprocessing과의 구분
- `preprocessing/` : 정제·집계·파생변수 생성 후 `data/processed/`에 저장 (결과물 = 데이터 파일)
- `analysis/` : 가공된 데이터로 분석·검정·모델링 (결과물 = 수치, 표, 그래프, 결론)
- 단, 표준화 등 학습 데이터 기준으로 계산하는 변환은 데이터 누수 방지를 위해 모델 코드 안에서 수행

## 데이터
- 입력: `data/processed/`의 전처리 완료 데이터
- 웹 대시보드에 쓰는 분석 결과는 Supabase에 적재
